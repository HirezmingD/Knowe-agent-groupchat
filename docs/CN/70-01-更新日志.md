## 当前版本：v1.0.25

> **说明**：本页为文档首次发布的更新日志，v1.0.25 条目覆盖**当前版本的功能面**。版本号口径与全站一致（v1.0.25.x 系列，见[30 配置 · 账户与身份 · 关于页：版本号与构建信息](30-04-账户与身份.md#关于页版本号与构建信息)）；以下条目按**新功能 / 修复 / 行为变化**三类标注。

**新功能**（本版功能面；条目取自已发布文档所覆盖的功能，细节见各链接页）：

- **装与配**——Windows x64 per-user 安装、安装包自带运行时、首启模型配置引导（选提供商 → 选模型 → 填 API Key → 连接测试通过才进入）（见[02 安装与系统要求](02-安装与系统要求.md)、[30 配置 · 模型与提供方](30-01-模型与提供方.md)）；
- **项目与团队**——项目 = 群聊 + 本地工作区目录；项目经理拆任务、24 种成员角色（每人有「擅长」与「不适合」两条边界）；加人 / 派活 / 移除都以审批卡等你确认（见[10 核心概念 · 项目与工作区](10-03-项目与工作区.md)、[10 核心概念 · 审批机制](10-04-审批机制.md)、[20 使用指南 · 创建项目与组建团队](20-01-创建项目与组建团队.md)、[50 参考 · 角色目录](50-01-角色目录.md)）；
- **派活与验收**——任务卡（谁 / 指令 / 项目经理的话与反馈历史）、成员流式工作、项目经理读文件核对后向你汇报（见[20 使用指南 · 派活与验收](20-03-派活与验收.md)）；
- **沟通**——群聊与群内私聊、`@` 提及、引用 / 转发 / 收藏、草稿按会话保存（见[20 使用指南 · 群聊与私聊](20-04-群聊与私聊.md)）；
- **文件**——附件（图片多模态直读、其余打包为文件内容块）、独立预览窗口多格式渲染（见[20 使用指南 · 文件与附件](20-05-文件与附件.md)、[20 使用指南 · 文件预览窗口](20-08-文件预览窗口.md)）；
- **知识与记忆**——知识资产（全局 / 项目两级作用域）、技能包三类、项目记忆三层结构、私聊内容写回项目记忆（见[20 使用指南 · 知识库与技能包](20-06-知识库与技能包.md)、[40 高级功能 · 知识策展](40-01-知识策展.md)、[40 高级功能 · 技能包管理](40-02-技能包管理.md)、[10 核心概念 · 记忆与上下文](10-05-记忆与上下文.md)）；
- **查找与成本**——全局搜索、收藏、联系人资料页；Token 用量面板（按日期范围筛选、按模型 / 按成员明细、金额以 ¥ 计）（见[20 使用指南 · 搜索、收藏与联系人](20-07-搜索收藏与联系人.md)、[20 使用指南 · Token 用量与费用](20-09-Token用量与费用.md)）；
- **配置与安全**——模型与提供方（主模型绑定与连接测试、辅助模型、按成员绑定模型、审批超时时限）、通知、外观、账户与身份；附件签名护栏、API Key 不落盘、内部标识脱敏、沙箱边界（见[30 配置 · 模型与提供方](30-01-模型与提供方.md)、[80 支持 · 安全与隐私](80-01-安全与隐私.md)）；
- **排障与维护**——连接状态六态徽章、后端崩溃自动拉起、目录失效恢复卡（见[60 故障排除 · 连接与后端故障](60-01-连接与后端故障.md)、[60 故障排除 · 目录与数据恢复](60-03-目录与数据恢复.md)）。

**修复**——本页不虚构修复条目：具体修复记录（涉及的具体报错与编号）以产品实际发布说明为准；自本页发布起，修复类条目随版本同步补充。

**行为变化**——同样以产品实际为准：涉及交互或口径变化会在对应功能页标注（如[审批、通知与托盘](30-02-审批通知与托盘.md)、[账户与身份](30-04-账户与身份.md)等），本页不编造跨版本的行为差异。

## 本版对你意味着什么

- **新用户**：本版功能面完整覆盖[快速开始](01-快速开始.md)的主循环——建项目 → 组队 → 派活 → 收到成果，照[快速开始](01-快速开始.md)走一遍即可确认本版够不够用；
- **日常用户**：每天用的功能都在本版功能面内——[派活与验收](20-03-派活与验收.md)、[群聊与私聊](20-04-群聊与私聊.md)、[文件与附件](20-05-文件与附件.md)、[知识库与技能包](20-06-知识库与技能包.md)，按需查阅即可；
- **管理者**：本版决策最该看两页——[审批机制：人与 AI 的边界](10-04-审批机制.md)（所有团队动作都经审批卡由你确认）与[安全与隐私](80-01-安全与隐私.md)（数据在本机、沙箱边界在哪）。

## 常见问题

**问：怎么知道我该不该升级？**
先看本版[新功能](#当前版本v1025)里有没有你需要的功能，再在「设置 → 账户与身份 → 关于」核对当前版本号与目标版本号（见[关于页：版本号与构建信息](30-04-账户与身份.md#关于页版本号与构建信息)）；本页随版本发布同步更新，升级前查最新条目即可。

**问：在哪里看我的版本号？**
「设置 → 账户与身份 → 关于」——版本号与构建信息都在那里（见[关于页：版本号与构建信息](30-04-账户与身份.md#关于页版本号与构建信息)）。

**问：更新日志多久更新一次？**
随版本发布节奏维护：有新版发布时，本页同步补充对应条目；更早版本（v1.0.24 及以前）的记录以产品实际为准，随文档发布节奏补充。
