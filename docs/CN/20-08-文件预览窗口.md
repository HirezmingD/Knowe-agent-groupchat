# 20 使用指南 · 文件预览窗口

> **摘要**：成员交的文件、你发的附件，都可以在**独立预览窗口**里直接看——不用在系统里另找软件。本页讲：怎么打开预览（点聊天流里的文件卡片）、独立窗口与多标签页、各格式怎么渲染（HTML / 图片 / PDF / Word / Excel / PPT / 代码 / Markdown / 纯文本）、缩放，以及「在文件管理器中显示」定位文件本体。

## 打开预览：点文件卡片

聊天流里的**文件卡片**就是预览的入口：点一下，文件在独立预览窗口里打开。两种文件卡片都行：

- **成员产出的文件**——成员提交报告时，成果以文件卡片出现在聊天流（见[20 使用指南 · 派活与验收 · 报告之后](20-03-派活与验收.md#报告之后项目经理怎么核对)）；
- **你发的附件**——见[20 使用指南 · 文件与附件](20-05-文件与附件.md)。

快速开始里也是这条路径：点聊天流里的文件卡片，在独立预览窗口里查看（HTML / 图片 / PDF / Word / 代码等均支持）。

> **提示**：预览只是「看」。文件本体一直在项目工作区目录里，你随时可以[在文件管理器中显示](#缩放与在文件管理器中显示)去动它。

## 独立窗口与多标签页

预览窗口有两条设计：

- **独立窗口**——预览在单独的窗口里打开，不占用聊天主界面；你可以一边看预览，一边继续在群里沟通；
- **多标签页**——可以同时打开多个文件，窗口内用标签切换，不用开一堆窗口。

## 按类型渲染

预览不是「一律当文本打开」，而是**按文件类型选择最合适的呈现**：

| 类型 | 预览表现 |
|:--|:--|
| **HTML** | 渲染成网页 |
| **图片** | 直接显示图片 |
| **PDF** | 分页显示 |
| **Word / Excel / PPT** | 按文档 / 表格 / 演示文稿渲染 |
| **代码** | 代码渲染（带高亮） |
| **Markdown** | 按渲染规则显示，与聊天流一致 |
| **纯文本** | 文本显示 |

> **说明**：Markdown 的渲染规则（GFM 表格、公式、代码高亮等）与聊天流保持一致，详见[50 参考 · Markdown 与公式渲染](50-02-Markdown与公式渲染.md)。

## 缩放与「在文件管理器中显示」

- **缩放**——预览窗口支持放大 / 缩小 / 适应窗口：看大图、读小字、核对细节都方便；
- **「在文件管理器中显示」**——一键在系统文件管理器里定位到文件本体。想复制、移动、编辑这个文件时最有用——预览窗口只读，改文件请到文件管理器里打开编辑。

文件本体就在项目的工作区目录里（见[10 核心概念 · 项目与工作区](10-03-项目与工作区.md)）——那是你的地盘，随时可以直接打开。

## 常见问题

**问：预览和直接打开文件有什么区别？**
预览在应用内完成，不用为每种格式装/找外部软件；文件本体不变，随时可以在文件管理器中定位。直接打开则交给系统关联的软件处理。

**问：预览打不开某些文件怎么办？**
先确认文件类型是否在[支持列表](#按类型渲染)里、文件本身是否损坏。如果打不开的是「模型读不懂内容」这类问题，那是另一回事——见[60 故障排除 · 模型与运行故障](60-02-模型与运行故障.md)。

**问：预览会修改原文件吗？**
不会。预览是只读查看；要编辑文件，用「在文件管理器中显示」定位后，用你自己的工具打开改。

**问：一次能预览几个文件？**
多标签页支持同时打开多个文件，用标签切换，不必开多个窗口。
