# 20 使用指南 · 搜索、收藏与联系人

> **摘要**：项目多了、消息多了，怎么快速找到东西？本页讲 Knowe 的查找与整理三件套：**全局搜索**（⌘K）一条命令直达六类目标；**收藏**会话与消息；**联系人资料页**——知知 / 项目经理 / 成员 / 群都能打开，上面有擅长领域、当前状态，以及「沙箱 + 记忆 + 工具」的权限边界说明。另附一个顺手小工具：每会话的聊天记录抽屉。

## 全局搜索：一条命令直达

按下 **⌘K** 唤起全局搜索面板，输入关键词，结果按目标类型分组，点选即可直达——不用一层层翻菜单。它叫「全局」是因为搜索范围横跨整个应用：会话、消息、联系人、收藏、知识卡、设置项都能搜。

典型场景：

- 记得群里说过什么，但记不清在哪条消息、哪个会话——搜原话，直接定位到消息；
- 想打开某个人的资料页，不想去花名册里找——搜名字；
- 想改某个设置（比如通知开关），不想在设置里翻——搜设置项。

![](docs/assets/S32-全局搜索面板（⌘K）.png)

## 六类搜索目标

| 目标 | 能搜到什么 | 典型用法 |
|:--|:--|:--|
| **会话** | 项目群聊、私聊 | 输入项目名，直达群聊 |
| **消息** | 聊天流里的消息内容 | 搜一句原话，定位到那条消息 |
| **联系人** | 知知 / 项目经理 / 成员 / 群 | 搜名字，打开资料页 |
| **收藏** | 你收藏的会话与消息 | 搜收藏标题，直达收藏 |
| **知识卡** | 知识库里的知识资产 | 搜「坑」类知识，直达知识卡 |
| **设置项** | 设置里的条目 | 搜「通知」，直达对应开关 |

> **提示**：全局搜索是「跨目标」的入口；想在**某一个**会话内部定位内容，用[会话内查找](#会话内查找与聊天记录抽屉)更精准。

## 收藏会话与消息

收藏是把重要内容「钉」住，方便随时回来：

- **收藏消息**——鼠标悬停消息，在操作菜单里点「收藏」（入口见[20 使用指南 · 群聊与私聊 · 消息操作](20-04-群聊与私聊.md#消息操作引用--转发--收藏--复制)）；
- **收藏会话**——把常用会话收进收藏，之后从收藏视图一键回来；
- **收藏视图**——集中查看所有收藏，按「会话 / 消息」两类排列；
- 在全局搜索里，收藏也是六类目标之一——搜收藏标题也能直达。

## 会话内查找与聊天记录抽屉

长会话里翻历史，两样东西配合用：

- **聊天记录抽屉**——每个会话都能打开记录抽屉，按时间翻历史消息；
- **消息内查找**——消息操作里的查找功能，在会话里定位关键词（见[20 使用指南 · 群聊与私聊](20-04-群聊与私聊.md)）。

加上全局搜索，就构成三层查找：**全局搜索**（跨会话找）→ **消息内查找**（会话内找）→ **聊天记录抽屉**（按时间翻），从「大概在哪」到「精确到句」都有办法。

## 联系人资料页

知知、项目经理、成员、群，都有各自的**资料页**。打开方式：从花名册、会话，或全局搜索的结果里点对应的对象即可。

资料页上最核心的一块是**擅长领域**：

| 对象 | 资料页上你会看到 |
|:--|:--|
| **知知（Zinnia）** | 平台级接待：帮你开项目、答疑 |
| **项目经理（Coordinator）** | 本项目总管：读项目、拆任务、派活、核对成果 |
| **成员（Worker）** | 角色与「擅长 / 不适合」两条边界、当前状态 |
| **群** | 这个项目是做什么的、成员构成 |

除了擅长领域，资料页还会显示**当前状态**（成员的状态点那一档，见[20 使用指南 · 管理团队 · 状态点](20-02-管理团队.md#状态点谁在忙谁闲着)），以及一段**权限边界说明**（见下节）。

![](docs/assets/S33-联系人资料页.png)

## 权限边界：沙箱、记忆与工具

资料页的权限边界说明，回答的是「这个对象到底能碰什么」，按三个维度讲：

| 维度 | 说明 |
|:--|:--|
| **沙箱** | 能读写哪些文件——默认只在工作区目录内（见[10 核心概念 · 项目与工作区](10-03-项目与工作区.md)） |
| **记忆** | 能看到哪些上下文——项目记忆、知识库（见[10 核心概念 · 记忆与上下文](10-05-记忆与上下文.md)） |
| **工具** | 能调用哪些能力——成员的工具箱 |

为什么资料页要放这个？因为 Knowe 里「能做什么」是有明确边界的，你随时能查、不用靠猜。这三个维度的完整解释（含哪些内容会被脱敏）见[40 高级功能 · 私聊、记忆与权限边界](40-03-私聊记忆与权限边界.md)。

## 常见问题

**问：全局搜索搜不到想找的东西怎么办？**
试试更短的关键词；如果目标在某个会话内部，用「消息内查找」定位更准；六类目标之外的场景，全局搜索不覆盖，换入口（如花名册、设置）找。

**问：收藏和别的标记是一回事吗？**
收藏就是 Knowe 里的「钉住」：消息与会话都能收，统一收在收藏视图里，也能被全局搜索搜到。

**问：打开成员资料页能看到什么？**
擅长领域（角色 + 擅长 / 不适合）、当前状态、权限边界说明。想深入了解「为什么派活要按角色挑人」，见[10 核心概念 · 知知 · 项目经理 · 成员](10-02-知知-项目经理-成员.md)。

**问：联系人和花名册是什么关系？**
花名册是项目内的**成员面板**（谁在忙、谁闲着）；联系人资料页是每个对象（知知 / 项目经理 / 成员 / 群）的**信息页**——从花名册或搜索结果都能进入。
