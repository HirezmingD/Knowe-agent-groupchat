## 什么时候需要联系我们

适合联系我们的场景：

- **文档与排障查过仍未解决**——60 故障排除三页、FAQ 都看过了，问题依旧；
- **疑似 bug**——行为与文档描述不符（如某个功能点了没反应、结果与说明不一致）；
- **功能建议 / 反馈**——希望 Knowe 更好用；
- **评估前确认**——采购、部署或合规评估前，需要进一步确认产品口径。

不适合的：能通过[提交问题前：先自查](#提交问题前先自查)解决的问题，请先自查——大概率比等回复更快，也避免重复提交。

## 反馈渠道与支持入口

反馈渠道与支持入口以**产品实际为准**，本页先用通用表述占位，随版本补充：

- **社区 / 讨论区**——常见问题解答与使用经验交流（入口占位，以产品实际为准）；
- **官方支持入口**——提交问题单或联系支持团队（入口占位，以产品实际为准）；
- **文档本身**——[60 故障排除](60-01-连接与后端故障.md)、[常见问题 FAQ](50-04-常见问题FAQ.md) 与[术语表](50-03-术语表.md)会随版本持续更新，先查再问。

## 提交问题前：先自查

提交前按顺序查这三处，大部分问题在这里就能解决：

1. **60 故障排除三页**——[连接与后端故障](60-01-连接与后端故障.md)（连不上、后端异常、端口问题）、[模型与运行故障](60-02-模型与运行故障.md)（连接测试失败、模型报错、成员卡住）、[目录与数据恢复](60-03-目录与数据恢复.md)（目录失效、备份与数据位置）；
2. **常见问题 FAQ**——[50 参考 · 常见问题 FAQ](50-04-常见问题FAQ.md)，按主题速查（模型 / 连接 / 文件 / 知识库 / 费用）；
3. **术语表**——[50 参考 · 术语表](50-03-术语表.md)，先确认说的是同一个词（如「审批卡」「花名册」「工作区目录」）。

自查后仍解决不了，再按下面的模板提交。

## 问题模板：版本、系统与复现步骤

提交问题时请填齐以下三块，其中**复现步骤为必填项**：

**① 版本**——「设置 → 账户与身份 → 关于」里的**版本号与构建信息**（见[30 配置 · 账户与身份 · 关于页：版本号与构建信息](30-04-账户与身份.md#关于页版本号与构建信息)）。

**② 系统**——操作系统与版本（如 Windows 11 23H2 x64）；如涉及网络，可补充网络环境（公司代理 / 直连等）。

**③ 复现步骤（必填）**——按「做了什么 → 期望什么 → 实际什么」三段填写：

> **做了什么**：例如「在项目 A 里给成员 B 派了一个『生成周报』的任务，上传了 `report.xlsx` 附件」。
>
> **期望什么**：例如「成员 B 读完附件并生成周报」。
>
> **实际什么**：例如「任务卡一直显示『工作中』超过 30 分钟，没有输出」。

补充建议：贴上报错原文（如「模型不支持该格式」「连接已断开」一类）、以及问题发生的大致时间，能显著加快定位。

## 常见问题

**问：问题模板里的「版本」在哪里找？**
「设置 → 账户与身份 → 关于」——版本号与构建信息都在那里（见[关于页：版本号与构建信息](30-04-账户与身份.md#关于页版本号与构建信息)）。

**问：怎么知道这是不是已知问题？**
先看[60 故障排除](60-01-连接与后端故障.md)三页与[常见问题 FAQ](50-04-常见问题FAQ.md)——已知问题与常见解法会优先沉淀在文档里；都查过仍无解，再按模板提交。

**问：反馈后一般多久有回复？**
以支持渠道的产品实际为准；模板填得越全（版本、系统、复现步骤），定位越快。本页不承诺具体时限。
