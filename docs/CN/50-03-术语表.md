## 角色与团队

| 术语 | 一句话定义 | 详见 |
|:--|:--|:--|
| **知知（Zinnia）** | 平台级 AI 接待，固定私聊窗口；帮你把「想做什么」聊清楚、提议开项目、日常答疑，项目建好后不进场 | [知知：平台级接待](10-02-知知-项目经理-成员.md#知知平台级接待) |
| **项目经理（Coordinator）** | 每个项目一位的总管：读项目、拆任务、提议加人 / 派活 / 移除、核对成果；**只有提议权，没有决定权** | [项目经理：每个项目一位的总管](10-02-知知-项目经理-成员.md#项目经理每个项目一位的总管) |
| **成员（Worker）** | 24 种角色之一，被拉进项目后执行具体任务、提交报告；每人有「擅长」与「不适合」两条边界 | [成员：24 种角色，可增可减](10-02-知知-项目经理-成员.md#成员24-种角色可增可减) |
| **角色目录** | 24 种成员角色的速查表（擅长 / 不适合），与产品内角色目录一致 | [50 参考 · 角色目录](50-01-角色目录.md) |
| **花名册** | 项目内成员的实时状态面板：谁在忙、谁闲着、谁已归档 | [花名册：团队的实时状态](20-02-管理团队.md#花名册团队的实时状态) |
| **归档** | 把成员移出工作阵容但保留全部历史、可随时请回的状态；Knowe 没有「删除成员」 | [减人：归档而不是删除](20-02-管理团队.md#减人归档而不是删除) |
| **停止** | 中断正在干活的成员；行内二次确认，5 秒内不点确认自动撤回 | [停止：中断正在干活的成员](20-02-管理团队.md#停止中断正在干活的成员) |

## 项目与工作区

| 术语 | 一句话定义 | 详见 |
|:--|:--|:--|
| **项目** | Knowe 的最小工作单元：一个群聊 + 一个本地工作区目录，缺一不可 | [项目：一个群聊与一个本地目录](10-03-项目与工作区.md#项目一个群聊与一个本地目录) |
| **工作区（目录）** | 建项目时自选的本地目录：团队产出的所有文件落在这里，AI 也只能读写这里的文件 | [工作区目录：AI 的沙箱](10-03-项目与工作区.md#工作区目录ai-的沙箱) |
| **沙箱** | 对工作区目录的通俗说法：AI 读写文件的唯一边界，「出不去」；附件是唯一的例外入口 | [工作区目录：AI 的沙箱](10-03-项目与工作区.md#工作区目录ai-的沙箱) |
| **目录失效** | 项目目录被移走 / 改名 / 删除后，聊天流内出现带 5 分钟倒计时的恢复卡（改名或重选目录） | [目录失效时的恢复](10-03-项目与工作区.md#目录失效时的恢复) |
| **数据目录** | 安装目录下的 `data/`（应用数据）与 `Logs/`（日志），备份与卸载时涉及 | [数据目录：data 与 Logs](40-04-环境变量与部署形态.md#数据目录data-与-logs) |

## 审批与决策

| 术语 | 一句话定义 | 详见 |
|:--|:--|:--|
| **审批卡** | 建项目 / 加人 / 派活 / 移除成员四类「人和活」动作以卡片形式等你确认的机制 | [四种审批卡](10-04-审批机制.md#四种审批卡) |
| **建群卡（创建项目卡）** | 知知提议开项目时弹出的审批卡：项目名 + 工作区目录（必选） | [第 2 步 · 确认建群卡：项目名与工作区目录](20-01-创建项目与组建团队.md#第-2-步--确认建群卡项目名与工作区目录) |
| **团队卡（组建团队卡）** | 项目经理提议加人时弹出的审批卡：候选成员列表（头像、名字、角色、擅长） | [第 4 步 · 确认团队卡：组队](20-01-创建项目与组建团队.md#第-4-步--确认团队卡组队) |
| **任务卡（派发任务卡）** | 项目经理提议派活时弹出的审批卡：派给谁 + 任务指令 + 项目经理附言，审批期间可反馈修改意见 | [任务卡详解：三个字段](20-03-派活与验收.md#任务卡详解三个字段) |
| **四终态** | 审批卡的四种结局：已确认 / 已拒绝 / 已超时 / 已取消；倒计时以服务端时钟为准 | [倒计时与四终态](10-04-审批机制.md#倒计时与四终态) |
| **审批超时** | 卡片倒计时走完自动撤回（≠ 拒绝）；时限可在设置里改为 5 / 10 / 30 / 60 / 180 / 300 秒或不限时 | [审批超时时间怎么改](10-04-审批机制.md#审批超时时间怎么改) |

## 沟通与消息

| 术语 | 一句话定义 | 详见 |
|:--|:--|:--|
| **群内私聊** | 双击花名册成员进入的、项目内的私聊通道（`dm:项目:成员`） | [群内私聊：双击花名册成员](20-04-群聊与私聊.md#群内私聊双击花名册成员) |
| **私聊不隐秘** | 群内私聊内容同样写回项目记忆，项目经理始终知道——私聊不是秘密通道 | [「私聊不隐秘」：边界说明](20-04-群聊与私聊.md#私聊不隐秘边界说明) |
| **引用 / 转发 / 收藏** | 对消息的三类操作：引用可跳回原文；转发带原格式并可加评论；收藏统一收进收藏视图 | [消息操作：引用 / 转发 / 收藏 / 复制](20-04-群聊与私聊.md#消息操作引用--转发--收藏--复制) |
| **文件卡片** | 聊天流里文件（附件或成员成果）的入口，点击在独立预览窗口打开 | [打开预览：点文件卡片](20-08-文件预览窗口.md#打开预览点文件卡片) |
| **连接状态徽章** | 窗口内的连接状态指示（连接中 / 已连接 / 重连中 / 已断开等），后端异常时可点「重试」 | [端口与后端：本地运行形态](40-04-环境变量与部署形态.md#端口与后端本地运行形态) |

## 知识与记忆

| 术语 | 一句话定义 | 详见 |
|:--|:--|:--|
| **记忆** | 项目级过程记录，分三层（最近活动 / 滚动摘要 / 历史活动段），自动发生、跨回合保持 | [项目记忆的三层结构](10-05-记忆与上下文.md#项目记忆的三层结构) |
| **知识资产** | AI 干活过程中蒸馏出的可复用经验，分五类（偏好 / 做法 / 坑 / 事实 / 决策），界面以四类标签（约定 / 坑 / 模式 / 清单）组织 | [知识资产：五类资产与四类标签](20-06-知识库与技能包.md#知识资产五类资产与四类标签) |
| **全局知识 / 项目知识** | 知识资产的两级作用域：全局知识所有项目可用，项目知识仅当前项目可用 | [两级作用域：全局与项目](20-06-知识库与技能包.md#两级作用域全局与项目) |
| **待审 / 生效中 / 已退役** | 知识资产的三个生命周期状态：待审等你表态、生效中团队可引用、已退役历史保留 | [生命周期：生效中、待审、已退役](20-06-知识库与技能包.md#生命周期生效中待审已退役) |
| **知识策展** | 对待审资产批准 / 驳回、退役与恢复、彻底删除、深钻证据与引用轨迹的高级操作 | [40 高级功能 · 知识策展](40-01-知识策展.md) |
| **技能包** | 承载可复用能力的三类包：系统自备（不可变）、项目经验（可策展）、第三方（独立生命周期） | [技能包：三类各有归属](20-06-知识库与技能包.md#技能包三类各有归属) |
| **记忆与知识的分工** | 记忆 = 过程（谁说了什么、做了什么），知识 = 沉淀（可复用的偏好、做法、坑、事实、决策） | [知识库与记忆的分工](10-05-记忆与上下文.md#知识库与记忆的分工) |

## 配置、成本与运维

| 术语 | 一句话定义 | 详见 |
|:--|:--|:--|
| **主模型** | 全团队默认使用、首次启动强制绑定的模型；之后可在设置里随时更换 | [主模型：绑定与连接测试](30-01-模型与提供方.md#主模型绑定与连接测试) |
| **辅助模型** | 可选的备用模型：配置后主模型不可用时会自动降级 | [辅助模型与自动降级](30-01-模型与提供方.md#辅助模型与自动降级) |
| **按成员绑定模型** | 给个别成员单独指定模型，其余成员仍用主模型 | [按成员绑定模型：何时值得用](30-01-模型与提供方.md#按成员绑定模型何时值得用) |
| **API Key** | 模型提供方的访问凭证：仅保存在本机、不写入浏览器存储，可在设置里清除 | [API Key 的安全说明（不落盘）](30-01-模型与提供方.md#api-key-的安全说明不落盘) |
| **Token 用量** | 本地统计的模型调用面板：按日期范围筛选 → 统计卡 → 趋势图 → 明细表 | [用量面板：从上到下怎么看](20-09-Token用量与费用.md#用量面板从上到下怎么看) |
| **费用（¥）** | Token 用量面板以人民币计的模型调用费用 | [费用如何计算（¥）](20-09-Token用量与费用.md#费用如何计算) |
| **环境变量（KNOWE_\*）** | 不用打开界面就能改的后台开关，按类别（后端 / 终端 / 网络 / 浏览器 / 记忆 / 技能）组织 | [KNOWE_\* 环境变量：类别与用途](40-04-环境变量与部署形态.md#knowe_-环境变量类别与用途) |
| **脱敏** | 界面自然语言中把成员内部 id、内部路径等内部标识打码，不暴露给用户 | [哪些内容会被脱敏](40-03-私聊记忆与权限边界.md#哪些内容会被脱敏) |
