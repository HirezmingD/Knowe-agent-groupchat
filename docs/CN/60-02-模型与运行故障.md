# 60 故障排除 · 模型与运行故障

## 症状一：连接测试失败

**症状**：在「设置 → 模型与提供方」改完主模型三要素后点连接测试失败，或首次启动引导第 2 步测试失败，卡片给出具体原因（见[30 配置 · 主模型：绑定与连接测试](30-01-模型与提供方.md#主模型绑定与连接测试)）。

**排查**：失败原因常见三类：

| 原因 | 含义 | 排查 / 解决 |
|:--|:--|:--|
| **认证失败** | API Key 错误或失效 | 检查 Key 是否完整、有无前后空格，更换后重测 |
| **网络不可达** | 连不上厂商 API | 检查网络与代理放行，见[02 安装与系统要求 · 网络要求](02-安装与系统要求.md#网络要求) |
| **余额不足 / 被限流** | 厂商侧限制 | 到厂商控制台查看额度和限流状态 |

**解决**：

1. 按上表修正后，重新点「测试并应用」（或引导卡片里的重测按钮）；
2. 首启引导里有三步快速自查，覆盖绝大多数情况：① API Key 是否完整、无前后空格；② 本机能否访问厂商官网 / API 域名；③ 是否为企业代理拦截（见[02 安装与系统要求 · 网络要求](02-安装与系统要求.md#网络要求)）；
3. 别忘一点：API Key 仅保存在本机，以 Windows DPAPI 密文写入设置文件、不写入浏览器存储，可在设置里清除后重填（见[API Key 的安全说明（系统加密落盘）](30-01-模型与提供方.md#api-key-的安全说明不落盘)）。

## 症状二：成员报「模型不支持某格式」

**症状**：成员在工作时报告类似「模型不支持某格式」的错误，某个附件读不进来。

**排查**：

1. 先确认文件是否在[20 使用指南 · 文件与附件 · 支持哪些格式](20-05-文件与附件.md#支持哪些格式)列表里；
2. 格式列表只是「支持范围」的说明——具体某个文件 AI 能不能读出内容，还取决于文件本身（是否损坏、是否加密等，见[文件与附件 · 常见问题](20-05-文件与附件.md#常见问题)）。

**解决**：不在支持列表里的，把内容**转成支持的格式**再喂——比如导出为 PDF、文本或表格，或者把关键内容**直接复制进消息**（同[50 参考 · FAQ · 文件](50-04-常见问题FAQ.md#文件)口径）。

> **提示**：模型读到的是**文件的内容**（图片走多模态直读、其余打包为文件内容块），不是「路径」——「读不了」通常是格式或文件本身的问题，不是路径问题（见[附件如何被 AI 读取](20-05-文件与附件.md#附件如何被-ai-读取)）。

## 症状三：成员卡住不动

**症状**：成员状态一直「工作中」，流式输出不再推进（逐字输出停住了）。

**排查**：先看他的流式输出是否还在推进；确实卡住了再动手（同[20 使用指南 · 派活与验收 · 常见问题](20-03-派活与验收.md#常见问题)的口径）。

**解决**：在**花名册**里**停止**他：

1. 在花名册找到状态为「工作中」的成员，点他那一行的「停止」按钮；
2. 点击后不会立即执行——出现行内二次确认（如「确认停止顾言正在进行的任务？」），**5 秒内不点确认，操作自动撤回**；
3. 点确认后，该成员中断当前工作，状态回到「待命」；**已产生的中间产出与聊天流中的记录全部保留**；
4. 停止后如果想继续，**重新派活**即可——停止的是「这一次执行」，不是这位成员本身。

操作细节与截图见[20 使用指南 · 管理团队 · 停止](20-02-管理团队.md#停止中断正在干活的成员)。

> **提示**：如果不止一位成员不动，先回[60 故障排除 · 连接与后端故障](60-01-连接与后端故障.md)看徽章是否为「已连接」——连接异常时成员也可能「卡住」（同[管理团队 · 常见问题](20-02-管理团队.md#常见问题)口径）。

## 辅助模型：自动降级兜底

主模型暂时不可用（如厂商侧限流、网络波动、Key 失效）时，配置了**辅助模型**会自动降级，避免团队因为主模型故障而卡住（见[30 配置 · 辅助模型与自动降级](30-01-模型与提供方.md#辅助模型与自动降级)）。

要点：

- 辅助模型在「设置 → 模型与提供方」里配置，与主模型并列，同样需要选择提供商、模型与可用的 API Key；
- 平时干活仍以主模型为准，辅助模型只在主模型不可用时顶上；
- 对可靠性要求高的场景，建议配一个与主模型**不同厂商**的辅助模型——把「单一提供方故障」的影响分散掉。

没配置辅助模型的话，主模型不可用时按[症状一](#症状一连接测试失败)排查修复。

## 常见问题

**问：连接测试通过了，但成员干活时还是报错？**
看报错内容落在哪一类：「模型不支持某格式」按[症状二](#症状二成员报模型不支持某格式)；卡住不动按[症状三](#症状三成员卡住不动)；持续异常先回[连接与后端故障](60-01-连接与后端故障.md)看徽章。

**问：换了 Key 还是认证失败？**
检查 Key 是否完整、有无前后空格，确认复制的是所选提供商的 Key；必要时在设置里清除后重填再测（见[症状一](#症状一连接测试失败)与[API Key 的安全说明（系统加密落盘）](30-01-模型与提供方.md#api-key-的安全说明不落盘)）。

**问：辅助模型也会不可用吗？**
会。所以建议与主模型选**不同厂商**，把「单一提供方故障」的影响分散掉（见[辅助模型与自动降级](30-01-模型与提供方.md#辅助模型与自动降级)）。

**问：停止成员会不会丢进度？**
不会丢已产出的东西：成员写好的文件在项目目录里，聊天记录在项目记忆里；丢的只是「这次没干完的活」，重新派一次即可（见[管理团队 · 常见问题](20-02-管理团队.md#常见问题)）。
