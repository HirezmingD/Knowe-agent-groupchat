# 02 安装与系统要求

> **摘要**：本页覆盖从下载安装包到第一次进入 Knowe 的全过程：系统要求、安装步骤（per-user、可改目录、可选快捷方式）、首次启动的模型配置引导（提供商 / 模型 / API Key / 连接测试）、网络要求，以及卸载时的数据保留规则。安装包自带 Python 运行时与 Chromium，你不需要安装任何额外依赖。

## 系统要求

| 项目 | 要求 |
|:--|:--|
| 操作系统 | Windows **x64（64 位）**；安装包仅提供 x64 架构版本 |
| 磁盘空间 | 安装后约占用 700 MB～1 GB（应用本体 + 自带后端运行时 + 无头浏览器），建议预留 2 GB 可用空间 |
| 内存 | 建议 8 GB 及以上（无硬性下限；团队越大、任务越重，占用越高） |
| 网络 | **必须能访问你选择的模型提供方 API**（HTTPS 出站），见[网络要求](#网络要求) |
| 无需另装 | Python、Node.js、Chrome / Edge 浏览器等均**不需要**——安装包内置 Python 运行时与 Chromium（Playwright） |

> **说明**：Knowe 是本地运行的应用：应用自带后端进程，窗口内有连接状态徽章（连接中 / 已连接 / 重连中 / 已断开等状态）。它只在你选择的模型提供方之间收发请求，不依赖任何额外账号或云服务。

## 下载安装包

从官网或发布渠道下载安装包，文件名为：

```
Knowe Setup 1.0.25.2.exe
```

## 安装步骤

安装是**向导式**的（不是一键静默安装），全程**不需要管理员权限**（per-user 安装，不写系统目录）。双击安装包后按向导走：

**第 1 步 · 欢迎页**：确认安装 Knowe，点击「下一步」。

![](docs/assets/S08-安装器欢迎页.png)

**第 2 步 · 选择安装目录**：默认安装到**当前用户**的程序目录（无需管理员即可写入的位置），你可以点「浏览」改成其他目录。**建议记住这个路径**——应用数据默认存放在这里（见[卸载与数据保留](#卸载与数据保留)）。

![](docs/assets/S09-选择安装目录页.png)

**第 3 步 · 快捷方式**：选择要创建的快捷方式，两个选项**默认勾选**，按需取消：

- 创建桌面快捷方式
- 创建开始菜单快捷方式

![](docs/assets/S10-快捷方式选择页.png)

**第 4 步 · 安装并完成**：点击「安装」，等待进度条走完；完成页可勾选「运行 Knowe」（默认勾选）并点击「完成」。

![](docs/assets/S11-安装完成页.png)

安装完成后，桌面 / 开始菜单出现 **Knowe** 快捷方式。双击打开，进入[首次启动：模型配置引导](#首次启动模型配置引导)。

> **安装问题排查**：如果安装包无法启动或提示损坏，删除后重新下载即可（安装包未做代码签名，Windows SmartScreen 可能弹出「已保护你的电脑」提示——这是未签名软件的常规提示，点「更多信息 → 仍要运行」即可继续）。详见「60 故障排除」分册（[连接与后端故障](60-01-连接与后端故障.md) · [模型与运行故障](60-02-模型与运行故障.md) · [目录与数据恢复](60-03-目录与数据恢复.md)）。

## 首次启动：模型配置引导

**第一次打开 Knowe 时，必须完成模型配置才能进入**——这是强制引导：背景雾化，其余界面全部锁定，只有配置卡片可以操作。原因很简单：你的 AI 团队要靠大模型才能干活，没有一个可用的大模型，进到主界面也无事可做。

引导卡片上方先选择**界面语言**（中文 / English）；下方是模型配置表单，顶部有三步指示器：

> `1 · 选择与填写  ›  2 · 连接测试  ›  3 · 进入`

**第 1 步 · 选择与填写**

1. **大模型提供商**：下拉选择厂商。Knowe 内置 20 余家提供方，例如：

   | 中文名 | 英文名 / 平台 |
   |:--|:--|
   | 深度求索 | DeepSeek |
   | 智谱 | Z.AI / GLM |
   | 月之暗面 | Kimi / Moonshot |
   | 通义 | Qwen Cloud |
   | 稀宇科技 | MiniMax |
   | 阶跃星辰 | StepFun |
   | 腾讯 | Tencent TokenHub |
   | — | OpenRouter、Anthropic、OpenAI、Google AI Studio、xAI、NovitaAI、Hugging Face 等 |

2. **模型**：选定服务商后，从其支持的模型列表中选择一个。
3. **API Key**：粘贴该厂商的 API Key。Key **仅保存在本机**（界面说明为「用于调用所选模型，仅保存在本机」），不会写入浏览器存储；在「设置 → 模型与提供方」里可以随时清除已保存的 Key。
4. 点「**确定**」封存配置（未选择模型时，「确定」不可用，卡片会提示「先选一个模型，再继续」）。

**第 2 步 · 连接测试**

封存配置后，Knowe 会**自动发起连接测试**；你也可以点「**测试并应用**」手动重测。测试通过后，卡片会显示类似「连接已通过，正在应用设置 · 320ms」的结果，并进入下一步。

**第 3 步 · 进入**

一切就绪后，「**进入 Knowe**」按钮亮起，点击即进入主界面，看到知知的欢迎消息。引导退场，其余界面解锁。

![](docs/assets/S12-首次启动模型配置引导卡片.png)

**测试失败时**，卡片会给出具体原因，常见三类：**认证失败**（Key 错误或失效）、**网络不可达**（连不上厂商 API，见[网络要求](#网络要求)）、**余额不足 / 被限流**（厂商侧限制）。修正后重新「测试并应用」即可。详见[60 故障排除 · 模型与运行故障](60-02-模型与运行故障.md)。

> **说明**：首次配置后，你随时可以在「设置 → 模型与提供方」里更换提供商、模型或 Key，也可以给个别成员绑定独立模型（详见[30 配置 · 模型与提供方](30-01-模型与提供方.md)）。

## 网络要求

Knowe 的联网需求很明确，只有一条主线：

- **必须能访问你选择的模型提供方 API**（HTTPS 出站）。不同厂商域名不同，例如 DeepSeek 为 `api.deepseek.com`；你在引导卡片里选哪家，就需要能连通哪家。
- 应用内部的后端在**本机**运行，默认使用 WS 8080 / HTTP 8081 端口；若被占用会自动避让到其他端口，一般无需手动处理。
- 如果在公司网络 / 代理环境，请放行到模型服务商的 HTTPS 出站；纯内网环境通常无法完成连接测试。

> **快速自查**：连接测试失败时，依次确认——① API Key 是否完整、无前后空格；② 本机能否访问厂商官网 / API 域名；③ 是否为企业代理拦截。前两条覆盖绝大多数情况。

## 卸载与数据保留

通过「设置 → 账户与身份 → 关于」或 Windows「设置 → 应用」卸载 Knowe。卸载器会先问一个问题：

> **保留聊天记录与项目数据**（默认勾选）：卸载后重新安装可恢复

- **勾选（默认）**：卸载**只删除程序文件**，你的聊天记录、项目数据与日志保留在安装目录的 `data/` 与 `Logs/` 下，重新安装后数据仍在。
- **取消勾选**：**彻底卸载**，连数据一起删除——这一步**不可恢复**，请确认不再需要这些数据再操作。

另外两点要知道：

- 卸载**不会删除**你磁盘上的项目文件夹——项目工作区目录是你自己选的（见[快速开始 · 第 2 步](01-快速开始.md#第-2-步--确认建群卡项目名与工作区目录)），它不在安装目录里，卸载不影响其中的文件。
- 安装目录里的 `data/` 存放应用数据（含聊天记录、项目数据），`Logs/` 存放日志；想备份数据，备份这两个目录即可。

![](docs/assets/S13-卸载器「保留数据」页.png)
