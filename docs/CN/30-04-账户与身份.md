## 设置 → 账户与身份

「账户与身份」是「设置」的一个分区，管两件事：你是谁——**昵称**与**头像**；以及 Knowe 本身是谁——**关于**（版本号、构建信息）。

## 昵称

在「设置 → 账户与身份」里可以设置你的**昵称**——它是你在 Knowe 里的身份标识，团队（项目经理、成员）用这个名字认识你。随时可以改。

## 头像上传

在「设置 → 账户与身份」里可以**上传头像**，替换默认头像。

![](docs/assets/S43-账户与身份设置.png)

## 关于页：版本号与构建信息

「设置 → 账户与身份 → 关于」展示 Knowe 的身份信息：

- **版本号**——当前安装的版本（v1.0.25.x 系列；安装包形如 `Knowe Setup 1.0.25.2.exe`，见[02 安装与系统要求](02-安装与系统要求.md)）；
- **构建信息**——构建号、构建时间等（以页面实际展示为准）。

**关于页也是卸载入口**：通过「设置 → 账户与身份 → 关于」或 Windows「设置 → 应用」都可以卸载 Knowe。卸载器会先问一个问题（见[02 安装与系统要求 · 卸载与数据保留](02-安装与系统要求.md#卸载与数据保留)）：

> **保留聊天记录与项目数据**（默认勾选）：卸载后重新安装可恢复

- **勾选（默认）**——卸载只删除程序文件，聊天记录、项目数据与日志保留在安装目录的 `data/` 与 `Logs/` 下，重新安装后数据仍在；
- **取消勾选**——彻底卸载，连数据一起删除，**不可恢复**。

另外两点要知道：

- 卸载**不会删除**你磁盘上的项目文件夹——工作区目录是你自己选的、不在安装目录里，卸载不影响其中的文件；
- 想备份数据，备份安装目录里的 `data/` 与 `Logs/` 即可。

![](docs/assets/S44-关于页.png)

## 常见问题

**问：版本号在哪里看？**
「设置 → 账户与身份 → 关于」。

**问：卸载会删掉我的项目文件吗？**
不会。工作区目录是你自己选的、不在安装目录里；卸载时默认也保留聊天记录与项目数据（重新安装可恢复）。

**问：改昵称和头像会影响团队吗？**
不会。它只更新你本人的身份信息，不影响团队构成与项目数据。

**问：卸载后重装，数据还在吗？**
卸载时勾选「保留聊天记录与项目数据」（默认），重新安装后数据仍在；取消勾选则是彻底卸载，不可恢复。
