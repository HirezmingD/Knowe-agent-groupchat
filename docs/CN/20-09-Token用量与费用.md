# 20 使用指南 · Token 用量与费用

> **摘要**：团队干活要调用模型，模型调用要花钱——Knowe 内置本地的 **Token 用量面板**，让你看清每一分花在哪。本页按面板的阅读顺序讲：按日期范围筛选 → 统计卡（总 token / 费用等）→ 趋势图 → 明细表（按模型 / 按成员双 Tab）；金额以 **¥** 计。末尾给**省 token 的常见做法**，都是基于本产品机制可落地的建议。

## 用量面板：从上到下怎么看

用量面板的阅读顺序，就是数据**逐层下钻**的顺序：

> **按日期范围筛选 → 统计卡（总 token / 费用等）→ 趋势图 → 明细表（按模型 / 按成员双 Tab）**

先圈定时间范围，再看总量，再观察变化趋势，最后下钻到「谁、用什么模型、花了多少」的明细。面板是**本地**的（Knowe 内置本地 Token 用量面板），随时可以打开查看，不依赖外部账单。

![](docs/assets/S37-Token 用量面板总览.png)

## 按日期范围筛选

面板顶部是**日期范围筛选**：选定起止日期后，面板上的统计卡、趋势图、明细表全部跟着这个范围走。

典型用途：

- **对账**——这个月 / 这周总共花了多少；
- **复盘**——上周哪几天、哪类任务消耗大；
- **对比**——改了模型或组队方式前后，用量有没有降下来。

## 统计卡与趋势图

- **统计卡**——所选范围内的汇总数字：总 token、费用等，一眼看总量；
- **趋势图**——用量随时间的变化曲线，看高峰与低谷，定位「哪天消耗特别大」。

两者配合：统计卡回答「总共多少」，趋势图回答「什么时候花得多」。

## 明细表：按模型 / 按成员

明细表用**双 Tab** 切换两个维度：

| Tab | 看什么 | 适合回答 |
|:--|:--|:--|
| **按模型** | 每个模型用了多少 token、费用多少 | 哪个模型是成本大头、不同模型成本对比 |
| **按成员** | 每个成员用了多少 | 谁在持续占用资源（成员越多、越活跃，占用越多，见[10 核心概念 · 审批机制 · 为什么所有团队动作都要审批](10-04-审批机制.md#为什么所有团队动作都要审批)） |

两个维度叠起来，就能定位到「哪位成员、跑在哪个模型上」的组合成本，成本大头一目了然。

![](docs/assets/S38-明细表「按模型 按成员」双 Tab.png)

## 费用如何计算（¥）

- **金额以 ¥ 计**——面板上的费用统一显示为人民币；
- 费用与你**实际调用的模型和 token 用量**有关：模型由你配置与选择（见[30 配置 · 模型与提供方](30-01-模型与提供方.md)），用量由团队的实际工作产生；
- 用量与费用统计在本机（本地面板），随查随看，方便你判断成本与收益。

## 省 token 的常见做法

省 token 不是「少用」，而是「同样的活少浪费」。下面这些做法都对应 Knowe 已有的机制：

| 做法 | 为什么省 | 详见 |
|:--|:--|:--|
| **队伍够用就好，别凑满** | 每个成员都持续占用模型调用与 token，人越少占用越低 | [创建项目与组建团队 · 常见问题](20-01-创建项目与组建团队.md#常见问题) |
| **闲置成员归档** | 归档后不再接活、不再占用 | [管理团队 · 减人：归档而不是删除](20-02-管理团队.md#减人归档而不是删除) |
| **卡住的成员及时停止** | 停止一次执行，避免空转烧 token | [管理团队 · 停止：中断正在干活的成员](20-02-管理团队.md#停止中断正在干活的成员) |
| **指令写清验收标准** | 减少「返工 → 重做」的重复调用 | [派活与验收 · 常见派活模式](20-03-派活与验收.md#常见派活模式) |
| **靠知识沉淀复用** | 不重复踩坑、不重复解释，同类活越干越省 | [知识库与技能包](20-06-知识库与技能包.md) |
| **理解记忆分层** | 旧内容压缩成滚动摘要，上下文不会无限膨胀 | [记忆与上下文 · 项目记忆的三层结构](10-05-记忆与上下文.md#项目记忆的三层结构) |

> **进阶**：给特定成员绑定更合适的模型（按成员绑定模型），让高价值任务用好模型、低价值任务用更省的选择——见[30 配置 · 模型与提供方 · 按成员绑定模型](30-01-模型与提供方.md#按成员绑定模型何时值得用)。

## 常见问题

**问：费用显示的是什么币种？**
人民币（¥）。

**问：用量统计的范围是什么？**
你选的日期范围；面板是本地的，统计的是本地发生的模型调用。

**问：为什么某个成员的费用特别高？**
看他被派了多少活、喂了多少文件、持续工作了多久——在明细表「按成员」Tab 下钻，再切「按模型」看他用的是哪个模型，就能定位原因。

**问：怎么让费用降下来？**
先看「省 token 的常见做法」一节：控制队伍规模、归档闲置、及时停止、指令写清验收标准、靠知识复用减少重复。

**问：用量面板的数据能导出吗？**
本页只讲面板怎么看；当前版本未提供用量导出，费用明细可在面板内查看。
