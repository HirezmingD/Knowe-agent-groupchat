# 20 使用指南 · 知识库与技能包

> **摘要**：让团队越用越聪明——这就是知识库的用处：AI 干活过程中蒸馏出的经验，被沉淀成可复用的知识资产，下次同类项目直接引用，不必再踩一遍。本页讲：五类知识资产如何呈现为界面的四类标签（约定 / 坑 / 模式 / 清单）、全局与项目两级作用域、知识卡上有什么（被引用次数、来源、证据清单、使用轨迹）、资产的生命周期（生效中 / 待审 / 已退役）与你能做的操作（批准、驳回、重命名、调整范围、退役、删除）、三类技能包，以及团队到底怎么把知识用起来。记忆与知识的分工（记忆 = 过程，知识 = 沉淀）见[10 核心概念 · 记忆与上下文](10-05-记忆与上下文.md)，本页讲的是操作面。

## 知识资产：五类资产与四类标签

知识库里的每一条，都是一条**知识资产**——AI 干活过程中蒸馏出的可复用经验。按内容，资产分五类：

| 资产类型 | 是什么 |
|:--|:--|
| **偏好** | 你（或项目）习惯怎么做 |
| **做法** | 可复用的步骤与方法 |
| **坑** | 踩过的坑，别再踩 |
| **事实** | 客观事实与口径 |
| **决策** | 定下来的事与依据 |

在界面上，这些资产用**四类标签**组织：**约定 / 坑 / 模式 / 清单**。两者不是两张皮，而是一件事的两面——五类讲「知识从哪来」，四标签讲「界面上怎么归」。常见对应大致是这样：

| 资产类型（内容） | 界面标签 | 举例 |
|:--|:--|:--|
| 偏好 | 约定 | 「周报用 A4 版式，PDF 与 md 同名」 |
| 做法 | 约定 / 模式 | 「验收前先让数据分析核对一遍数字」 |
| 坑 | 坑 | 「某框架的某版本有已知 bug」 |
| 事实 | 清单 | 「生产环境地址与端口」 |
| 决策 | 清单 | 「本月上线范围的决定」 |

> **提示**：不必纠结一一对应——同一条知识按内容归进最合适的标签，具体归类由内容与你的策展决定。

## 两级作用域：全局与项目

知识资产分**两级作用域**：

| 作用域 | 谁能用 | 适合放什么 |
|:--|:--|:--|
| **全局知识** | 所有项目 | 跨项目通用的偏好、做法、常踩的坑 |
| **项目知识** | 仅当前项目 | 这个项目特有的决策、事实、约定 |

选择作用域的意义：全局知识让你不用在每个项目里重复交代偏好；项目知识则保证「这个项目的事」只在这个项目里生效，不污染别的项目。作用域可以在知识卡上**调整**（见[生命周期](#生命周期生效中待审已退役)一节的操作清单）。

## 知识卡：引用次数、来源与证据

每条知识以一张**知识卡**呈现，卡上除了标题与类型标签，还有四样关键信息：

| 卡片信息 | 回答什么问题 |
|:--|:--|
| **被引用 N 次** | 这条知识被多少次任务 / 对话引用过——用得越多越可信 |
| **来源 M 份** | 它从多少份材料里提炼出来 |
| **证据清单** | 支撑这条知识的来源（消息、文件）——每一条都能追到出处 |
| **使用轨迹** | 它被哪些任务 / 项目用过 |

这套信息的意义：**知识不是拍脑袋**——任何一条资产都能回答「从哪来、被谁用过、靠不靠谱」，这也是它区别于普通聊天记录的地方。

## 生命周期：生效中、待审、已退役

知识资产有一个生命周期，三个状态：

| 状态 | 含义 | 谁决定的 |
|:--|:--|:--|
| **待审** | 刚从项目过程里提炼出来，还没生效 | 等你表态 |
| **生效中** | 已批准，团队可引用 | 你批准后 |
| **已退役** | 不再生效，历史保留 | 你主动退役 |

你（或经你批准）可以做的操作：

- **批准 / 驳回**——对待审资产表态：批准则生效，驳回则不进入知识库；
- **重命名**——把标题改得更清晰；
- **调整范围**——在全局与项目之间切换作用域；
- **退役**——让一条资产停止生效（可恢复）；
- **彻底删除**——不可逆，操作前请确认。

> **注意**：退役与恢复、彻底删除、证据深钻属于知识策展的高级操作，详见[40 高级功能 · 知识策展](40-01-知识策展.md)；本页只说明「有这些操作」。

## 技能包：三类各有归属

除了知识资产，项目还挂着一类叫**技能包**的能力集合，分三类：

| 类型 | 是什么 | 能否修改 |
|:--|:--|:--|
| **系统自备技能** | 应用内置（携带 SKILL.md 定义）的基础能力 | 不可变 |
| **项目经验技能** | 从项目的核心知识导出，随项目沉淀 | 可策展 |
| **第三方技能包** | 独立安装目录与独立生命周期的外部技能 | 可安装 / 卸载，有独立生命周期 |

一句话区分：**系统技能是出厂自带，项目经验技能是你们自己攒的，第三方技能包是外面装的**。技能包的安装、卸载与生命周期管理见[40 高级功能 · 技能包管理](40-02-技能包管理.md)。

## 团队如何消费知识

知识库不是「存着好看的」，团队的消费路径是闭环的：

1. **干活时引用**——成员执行任务时，会引用与当前任务相关的知识资产（偏好、做法、坑……），引用会记录在知识卡的「被引用 N 次」里；
2. **沉淀回来**——干活过程中发现的新经验，蒸馏成新的待审资产，等你批准；
3. **跨项目复用**——全局知识对所有项目生效：下次同类项目直接引用，不必再踩一遍（记忆 = 过程，知识 = 沉淀，见[10 核心概念 · 记忆与上下文 · 知识库与记忆的分工](10-05-记忆与上下文.md#知识库与记忆的分工)）。

所以知识库越用越「懂你」：你在里面攒的偏好与坑越多，团队在后续项目里就越少走弯路、越少重复解释。

## 常见问题

**问：知识是自动产生的吗？**
自动记录的是**记忆**（过程）；**知识是沉淀**，需要从项目过程里提炼，而且要走策展——待审资产要你批准才生效（见[生命周期](#生命周期生效中待审已退役)）。

**问：知识库和记忆到底有什么区别？**
记忆 = 过程（谁说了什么、做了什么、结果如何）；知识 = 沉淀（可复用的偏好、做法、坑、事实、决策）。一张对比表见[10 核心概念 · 记忆与上下文 · 知识库与记忆的分工](10-05-记忆与上下文.md#知识库与记忆的分工)。

**问：删掉的知识还能找回来吗？**
退役可以恢复；**彻底删除不可逆**，操作前务必确认。策展细节见[40 高级功能 · 知识策展](40-01-知识策展.md)。

**问：项目知识能升级成全局知识吗？**
能——在知识卡上**调整范围**，把作用域从「项目」切到「全局」即可。

**问：技能包坏了或想换掉怎么办？**
系统技能不可变；项目经验技能可策展；第三方技能包可卸载重装、走自己的生命周期——见[40 高级功能 · 技能包管理](40-02-技能包管理.md)。
