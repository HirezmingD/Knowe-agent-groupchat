# 50 参考 · Markdown 与公式渲染

> **摘要**：Knowe 的聊天流（以及文件预览中的 Markdown）按一套固定的 Markdown 规则渲染。本页列出支持的语法清单：GFM 表格 / 删除线 / 任务列表 / 自动链接，`$` / `$$` / `\[ \]` 公式（KaTeX 渲染），代码高亮与行号，单换行；以及一条安全说明——HTML 会被剥离。本页只列产品规划口径内明确点名的特性，其余语法特性以产品实际为准。

## 适用范围：聊天流与文件预览

这套渲染规则同时作用于两处，口径一致：

- **聊天流**——你和团队发的消息按此规则渲染；
- **文件预览中的 Markdown**——预览窗口里的 `.md` 文件「按渲染规则显示，与聊天流一致」（见[20 使用指南 · 文件预览窗口 · 按类型渲染](20-08-文件预览窗口.md#按类型渲染)）。

> **提示**：输入区里 Enter 是换行、Ctrl+Enter 是发送——多行内容、带公式与代码的指令就是这么写出来的（见[20 使用指南 · 群聊与私聊 · 输入区：换行与发送](20-04-群聊与私聊.md#输入区换行与发送)）。

## 支持的语法清单

| 语法 | 写法 | 说明 |
|:--|:--|:--|
| **GFM 表格** | `\| 列 1 \| 列 2 \|` | 管道分隔的表格，首行表头 |
| **删除线** | `~~文字~~` | 文字加删除线 |
| **任务列表** | `- [ ] 未完成` / `- [x] 已完成` | 复选框，可勾选 |
| **自动链接** | 直接写 URL | 可点击的链接 |
| **行内公式** | `$公式$` | KaTeX 渲染的行内公式 |
| **块级公式** | `$$公式$$` 或 `\[ 公式 \]` | 独占一行、KaTeX 渲染的块级公式 |
| **代码** | 代码围栏 + 语言名 | 代码高亮 + 行号 |
| **换行** | 单个换行符 | 单独一次换行即显示为换行 |

> **说明**：GFM 是 GitHub 风格的 Markdown 方言，标题、段落、列表、粗体、斜体、引用、链接与图片等基础语法同样可用；上表只列出产品规划中**明确点名**的特性。

## 公式：KaTeX 渲染

- **行内公式**：`$...$`——公式嵌在文字里，随文字流显示；
- **块级公式**：`$$...$$` 或 `\[ ... \]`——公式独占一行显示。

公式由 **KaTeX** 渲染。写公式时让前后留出空格会更清晰，例如：

> 质能方程可以写作行内公式 `$E = mc^2$`，或写成块级公式 `$$E = mc^2$$`。

## 代码：高亮与行号

代码块用围栏（三个反引号）包裹，标注语言名即可获得**语法高亮**，行首会显示**行号**。例如在消息里写：

````markdown
```python
def hello():
    print("hi")
```
````

（示例仅供展示写法；具体渲染效果以产品实际为准。）

## 换行：单换行

与「必须空一行才分段」的严格 Markdown 不同，Knowe 里**单个换行符就会显示为换行**——聊天消息里写多行、逐条列举，不会挤成一团。这也是输入区「Enter 换行」设计的原因（见[20 使用指南 · 群聊与私聊 · 输入区：换行与发送](20-04-群聊与私聊.md#输入区换行与发送)）。

## 安全说明：HTML 会被剥离

出于安全考虑，消息或文件中的 **HTML 标签会被剥离**——不会被当作网页执行或渲染，只按 Markdown 文本处理。想展示一段代码或标记语言本身，用代码块包起来即可。
