# 40 高级功能 · 环境变量与部署形态

> **摘要**：本页面向**进阶用户与特殊环境**（公司网络、端口冲突、数据备份），讲 Knowe 的部署形态：应用自带后端进程与本机端口（默认 WS 8080 / HTTP 8081，被占用时自动避让）、数据目录（安装目录下的 `data/` 与 `Logs/`）、以及 **KNOWE_\*** 环境变量的类别与用途。**绝大多数用户不需要看本页、也不需要设置任何环境变量**——默认配置即可正常工作；本页主要为排障与调优准备。具体变量名随版本补充、以产品实际为准，本页不臆造。

## 为什么会有环境变量

Knowe 是**本地运行**的应用：应用自带后端进程，模型请求从本机直接发给模型提供方（见[02 安装与系统要求 · 网络要求](02-安装与系统要求.md#网络要求)），不依赖额外账号或云服务。在这样的本地架构里，**环境变量**是「不用打开界面就能改的后台开关」——供进阶用户在特殊环境下调整运行行为，例如：

- 公司网络 / 代理环境下的连通性调优；
- 端口被占用时的处理；
- 数据目录的备份与迁移。

**命名约定**：Knowe 的相关环境变量以 **KNOWE_** 为前缀，按类别组织（后端 / 终端 / 网络 / 浏览器 / 记忆 / 技能等开关）。具体变量名、取值与默认值属于随版本发布的参考内容——**本页只说明类别与用途，不臆造变量名**。

## 端口与后端：本地运行形态

- 应用自带后端进程在**本机**运行，默认使用 **WS 8080 / HTTP 8081** 端口（见[02 安装与系统要求 · 网络要求](02-安装与系统要求.md#网络要求)）；
- 端口被占用时会**自动避让**到其他端口——一般无需手动处理；
- 窗口内有**连接状态徽章**（连接中 / 已连接 / 重连中 / 已断开等状态），后端异常时可通过「重试」重启后端（详细排障见[60 故障排除 · 连接与后端故障](60-01-连接与后端故障.md)）。

## 数据目录：data 与 Logs

Knowe 的数据都在本机，两处目录要分清：

| 目录 | 存放什么 | 位置 |
|:--|:--|:--|
| **`data/`** | 应用数据：聊天记录、项目数据 | 安装目录下（见[02 安装与系统要求 · 卸载与数据保留](02-安装与系统要求.md#卸载与数据保留)） |
| **`Logs/`** | 日志 | 安装目录下（同上） |
| **工作区目录** | 团队产出的文件 | 你建项目时自选的本地目录，**不在安装目录里**（见[10 核心概念 · 项目与工作区](10-03-项目与工作区.md)） |

要点：

- **备份**：想备份数据，备份安装目录里的 `data/` 与 `Logs/` 即可（[30 配置 · 账户与身份 · 关于页](30-04-账户与身份.md#关于页版本号与构建信息)同口径）；
- **卸载**：默认保留 `data/` 与 `Logs/`（重新安装可恢复）；取消勾选则连数据一起删除、不可恢复（见[02 安装与系统要求 · 卸载与数据保留](02-安装与系统要求.md#卸载与数据保留)）。

## KNOWE_* 环境变量：类别与用途

KNOWE_* 环境变量按类别提供开关与调优项，规划口径如下：

| 类别 | 用途（规划口径） | 具体变量名 |
|:--|:--|:--|
| **后端** | 后端进程的运行与端口相关开关 | 以产品实际为准，随版本补充 |
| **终端** | 终端相关行为的开关 | 以产品实际为准，随版本补充 |
| **网络** | 网络与代理相关调优 | 以产品实际为准，随版本补充 |
| **浏览器** | 内置浏览器（Chromium / Playwright）相关设置 | 以产品实际为准，随版本补充 |
| **记忆** | 记忆与上下文相关开关 | 以产品实际为准，随版本补充 |
| **技能** | 技能（SKILL）相关开关 | 以产品实际为准，随版本补充 |

> **重要**：上表列出的是**类别与用途**，不是具体变量名。具体变量名、取值与默认值随版本发布、以产品实际为准；本页不臆造名称。需要用到的用户，请以产品内说明或后续随版本发布的参考内容为准。

## 进阶用户的调优选项

基于本页已讲的事实，进阶用户能调的主要是这几处：

- **端口**：默认 WS 8080 / HTTP 8081，被占用会自动避让——一般无需处理；排障时留意本机是否有其他程序占用这两个端口（详细排障见[60 故障排除 · 连接与后端故障](60-01-连接与后端故障.md)）；
- **网络 / 代理**：公司网络或代理环境需放行到模型服务商的 HTTPS 出站（[02 安装与系统要求 · 网络要求](02-安装与系统要求.md#网络要求)）；
- **数据备份 / 迁移**：备份安装目录下的 `data/` 与 `Logs/`；工作区目录是你自选的，可随时在文件管理器里访问；
- **资源预留**：系统要求建议预留约 2 GB 可用磁盘空间、8 GB 内存（团队越大、任务越重，占用越高，见[02 安装与系统要求 · 系统要求](02-安装与系统要求.md#系统要求)）。

## 常见问题

**问：我需要设置环境变量吗？**
绝大多数用户不需要——默认配置即可正常工作。环境变量主要面向进阶用户在特殊环境（代理、端口冲突、数据备份）下的调优。

**问：端口被占了会怎样？**
后端会自动避让到其他端口，一般无需手动处理；排障时留意本机是否有程序占用 8080 / 8081。

**问：数据存在哪、怎么备份？**
安装目录下的 `data/`（应用数据）与 `Logs/`（日志），备份这两个目录即可；工作区目录是自选的产出落点，不在安装目录里。

**问：为什么本页没有具体变量名？**
具体变量名、取值与默认值随版本发布、以产品实际为准——本页只说明类别与用途，不臆造。
