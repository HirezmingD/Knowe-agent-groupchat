# 60 故障排除 · 目录与数据恢复

> **摘要**：项目 = 群聊 + 一个本地工作区目录。当你在文件管理器里把项目文件夹**移走、改名或删除**后，项目会「找不到」它的目录——这就是**目录失效**。本页讲：目录失效时聊天流里弹出的**恢复卡**（5 分钟倒计时）怎么用、**改名 / 重选目录**两条恢复路径分别适用什么情况，以及 Knowe 的数据在安装目录的哪里（`data/` 与 `Logs/`），备份、卸载时用得上。

## 症状：项目目录找不到了

**症状**：你在文件管理器里把项目文件夹移走、改名或删除了；回到 Knowe，项目聊天流内出现一张**目录恢复卡**（见[10 核心概念 · 项目与工作区 · 目录失效时的恢复](10-03-项目与工作区.md#目录失效时的恢复)）。

**背景**：项目绑定的是**目录路径**——目录一旦被移动或改名，项目就找不到它了，这就是**目录失效**（术语定义见[50 参考 · 术语表 · 项目与工作区](50-03-术语表.md#项目与工作区)）。

**重要**：**删除目录 ≠ 删除项目**——项目记录与聊天记录仍在本机数据里，只是暂时找不到文件落点。

## 恢复卡：5 分钟倒计时

- 恢复卡出现在**聊天流内**，带 **5 分钟倒计时**，给你两个选择：**改名**或**重选目录**（见[目录失效时的恢复](10-03-项目与工作区.md#目录失效时的恢复)）；
- 倒计时结束未处理，卡片会失效，但你仍然可以**主动发起恢复**（见下文[恢复卡失效后怎么办](#恢复卡失效后怎么办)）。

## 路径一：改名（目录还在，路径变了）

**适用**：目录被**移动 / 改名**的情况——文件夹还在磁盘上，只是路径变了。

**操作**：在恢复卡上选择「**改名**」，把项目记录更新到目录的**新路径**。

**说明**：改名只更新路径绑定，不动任何文件；改完后项目恢复，团队照常在原目录里读写（绑定关系见[项目名与目录的绑定](10-03-项目与工作区.md#项目名与目录的绑定)）。

## 路径二：重选目录（目录确实没了）

**适用**：目录**确实没了**（被删除）的情况。

**操作**：在恢复卡上选择「**重选目录**」，给项目换一个工作区目录。

**说明**：旧目录里的文件如果还在磁盘上（比如被移走但没删），重选前可以先去文件管理器里找到它、把文件搬进新目录；重选后，新目录成为团队读写的范围（沙箱口径见[工作区目录：AI 的沙箱](10-03-项目与工作区.md#工作区目录ai-的沙箱)）。

## 恢复卡失效后怎么办

恢复卡倒计时结束后未处理，卡片会失效——但这只代表「这张卡片不再倒计时」，**不影响恢复本身**：你仍然可以主动发起恢复，操作与卡片上一致（改名或重选目录，见[目录失效时的恢复](10-03-项目与工作区.md#目录失效时的恢复)）。具体入口以产品实际为准。

## 数据在安装目录的哪里

Knowe 的数据都在本机，两处目录要分清（见[40 高级功能 · 数据目录：data 与 Logs](40-04-环境变量与部署形态.md#数据目录data-与-logs)）：

| 目录 | 存放什么 | 位置 |
|:--|:--|:--|
| **`data/`** | 应用数据：聊天记录、项目数据 | 安装目录下 |
| **`Logs/`** | 日志 | 安装目录下 |
| **工作区目录** | 团队产出的文件 | 你建项目时自选的目录，**不在安装目录里** |

要点：

- **备份**：想备份数据，备份安装目录里的 `data/` 与 `Logs/` 即可；
- **卸载**：默认保留 `data/` 与 `Logs/`（重新安装可恢复）；取消勾选则连数据一起删除、**不可恢复**（见[02 安装与系统要求 · 卸载与数据保留](02-安装与系统要求.md#卸载与数据保留)）；
- **卸载不会删你的项目文件夹**：工作区目录是你自己选的，不在安装目录里，卸载不影响其中的文件（见[卸载与数据保留](02-安装与系统要求.md#卸载与数据保留)）。

## 常见问题

**问：目录被删了，里面的文件还能找回吗？**
看文件本身有没有备份（如回收站、网盘/同步盘）。Knowe 处理的是「路径绑定」的恢复，不替你找回被删的文件；但**删除目录 ≠ 删除项目**——项目记录与聊天记录仍在本机数据里（见[目录失效时的恢复](10-03-项目与工作区.md#目录失效时的恢复)）。

**问：改名和重选目录有什么区别？**
改名用于目录被移动 / 改名（路径更新，文件不动）；重选目录用于目录确实没了（换一个工作区目录）（见[目录失效时的恢复](10-03-项目与工作区.md#目录失效时的恢复)）。

**问：项目名能改吗？工作区目录呢？**
项目名随时可以改（改的是群聊名字）；目录的路径绑定在创建时确定，之后要换目录属于「目录失效」的恢复场景（见[项目名与目录的绑定](10-03-项目与工作区.md#项目名与目录的绑定)）。

**问：备份该备份哪里？**
安装目录下的 `data/` 与 `Logs/`；工作区文件在你自选的目录里，可一并自行备份（见[数据目录：data 与 Logs](40-04-环境变量与部署形态.md#数据目录data-与-logs)）。
