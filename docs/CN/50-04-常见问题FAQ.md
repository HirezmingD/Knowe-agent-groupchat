## 模型

**问：首次启动的模型配置引导能跳过吗？**
不能。首启强制引导是必经入口——不配置完一个可用模型，其余 UI 全部锁定（见[02 安装与系统要求 · 首次启动：模型配置引导](02-安装与系统要求.md#首次启动模型配置引导)）。

**问：换主模型要重新走一遍首启引导吗？**
不用。首启引导只在第一次进入时出现；之后换提供商、模型或 Key，在「设置 → 模型与提供方」里改完、跑一次连接测试即可（见[30 配置 · 模型与提供方 · 主模型：绑定与连接测试](30-01-模型与提供方.md#主模型绑定与连接测试)）。

**问：所有成员都用同一个模型吗？**
默认是。你可以按成员绑定独立模型，让个别成员用别的模型（见[30 配置 · 按成员绑定模型：何时值得用](30-01-模型与提供方.md#按成员绑定模型何时值得用)）。

**问：API Key 存在哪里？会不会被传走？**
Key 仅保存在本机，以 Windows DPAPI 密文写入设置文件、不写入浏览器存储，在设置里可随时清除；Knowe 只在所选模型提供方之间收发请求，不依赖额外账号或云服务（见[API Key 的安全说明（系统加密落盘）](30-01-模型与提供方.md#api-key-的安全说明不落盘)）。

**问：主模型不可用时怎么办？**
配置了辅助模型会自动降级；没配置的话，先在「设置 → 模型与提供方」里排查——认证失败、网络不可达、余额不足 / 被限流是三类常见原因（见[辅助模型与自动降级](30-01-模型与提供方.md#辅助模型与自动降级)）；详细排障见[60 故障排除 · 模型与运行故障](60-02-模型与运行故障.md)。

## 连接

**问：连接状态徽章显示异常（断线 / 重连中）怎么办？**
先点徽章旁的「重试」重启后端；仍不行再排查本机网络与端口占用。徽章状态说明见[40 高级功能 · 端口与后端：本地运行形态](40-04-环境变量与部署形态.md#端口与后端本地运行形态)；详细排障见[60 故障排除 · 连接与后端故障](60-01-连接与后端故障.md)。

**问：端口被占用会怎样？**
后端会自动避让到其他端口，一般无需手动处理；排障时留意本机是否有其他程序占用 8080 / 8081（见[环境变量与部署形态 · 端口与后端：本地运行形态](40-04-环境变量与部署形态.md#端口与后端本地运行形态)）。

**问：我需要设置环境变量吗？**
绝大多数用户不需要——默认配置即可正常工作。环境变量主要面向进阶用户在特殊环境（代理、端口冲突、数据备份）下的调优（见[KNOWE_* 环境变量：类别与用途](40-04-环境变量与部署形态.md#knowe_-环境变量类别与用途)）。

**问：在群里说了需求却迟迟没反应？**
先看窗口顶部连接状态徽章是否为「已连接」；不是的话点「重试」重启后端（见[20 使用指南 · 创建项目与组建团队 · 开始之前](20-01-创建项目与组建团队.md#开始之前)）。

## 文件

**问：AI 读不了某个格式怎么办？**
先确认是否在支持格式列表里；不在的话，把内容转成支持的格式（如导出为 PDF、文本或表格）再喂，或把关键内容直接复制进消息（见[20 使用指南 · 文件与附件 · 支持哪些格式](20-05-文件与附件.md#支持哪些格式)）。

**问：为什么 AI 不能直接读我电脑上任意一个文件？**
这是安全边界设计：团队默认只读写工作区目录（沙箱）；附件是唯一例外入口，且必须经你亲手选择、由应用确认并签名路径后才被读取（见[安全护栏：只有你亲手选的文件才会被读取](20-05-文件与附件.md#安全护栏只有你亲手选的文件才会被读取)）。

**问：预览打不开某些文件怎么办？**
先确认文件类型是否在支持列表里、文件本身是否损坏；预览只是查看，要改文件请「在文件管理器中显示」后用你自己的工具打开（见[20 使用指南 · 文件预览窗口 · 按类型渲染](20-08-文件预览窗口.md#按类型渲染)）。

**问：拖错文件了能撤回吗？**
发送前可以在输入区的附件块上点「移除」；发送后它作为消息留在聊天流里，可用消息操作（引用 / 转发 / 收藏 / 复制）处理（见[20 使用指南 · 文件与附件 · 添加附件：点选或拖拽](20-05-文件与附件.md#添加附件点选或拖拽)）。

## 知识库

**问：知识是自动产生的吗？**
自动记录的是**记忆**（过程）；**知识是沉淀**，需要从项目过程里提炼并走策展——待审资产要你批准才生效（见[知识生命周期：生效中、待审、已退役](20-06-知识库与技能包.md#生命周期生效中待审已退役)）。

**问：知识库和记忆到底有什么区别？**
记忆 = 过程（谁说了什么、做了什么、结果如何）；知识 = 沉淀（可复用的偏好、做法、坑、事实、决策）。一张对比表见[10 核心概念 · 记忆与上下文 · 知识库与记忆的分工](10-05-记忆与上下文.md#知识库与记忆的分工)。

**问：删掉的知识还能找回来吗？**
退役可以恢复；**彻底删除不可逆**，操作前务必确认（见[40 高级功能 · 知识策展 · 彻底删除：不可逆](40-01-知识策展.md#彻底删除不可逆)）。

**问：项目知识能升级成全局知识吗？**
能——在知识卡上**调整范围**，把作用域从「项目」切到「全局」即可（见[两级作用域：全局与项目](20-06-知识库与技能包.md#两级作用域全局与项目)）。

**问：技能包坏了或想换掉怎么办？**
系统技能不可变；项目经验技能可策展；第三方技能包可卸载重装、走自己的生命周期（见[40 高级功能 · 技能包管理](40-02-技能包管理.md)）。

**问：私聊里说的话，项目经理真的都知道吗？**
知道。群内私聊内容写回项目记忆，项目经理始终掌握全局——「私聊不隐秘」是 Knowe 的明确边界（见[20 使用指南 · 群聊与私聊 · 「私聊不隐秘」：边界说明](20-04-群聊与私聊.md#私聊不隐秘边界说明)）。

## 费用

**问：费用显示的是什么币种？**
人民币（¥）。用量面板的范围是你选的日期范围，统计的是本地发生的模型调用（见[20 使用指南 · Token 用量与费用 · 费用如何计算](20-09-Token用量与费用.md#费用如何计算)）。

**问：为什么某个成员的费用特别高？**
在明细表「按成员」Tab 下钻，看他被派了多少活、喂了多少文件、持续工作了多久；再切「按模型」看用的是哪个模型，就能定位原因（见[明细表：按模型 / 按成员](20-09-Token用量与费用.md#明细表按模型--按成员)）。

**问：怎么让费用降下来？**
看「省 token 的常见做法」：控制队伍规模、归档闲置、及时停止、指令写清验收标准、靠知识复用减少重复（见[省 token 的常见做法](20-09-Token用量与费用.md#省-token-的常见做法)）。
